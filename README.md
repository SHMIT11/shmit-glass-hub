# Shmit Hub

СОЗДАЙ ПОЛНОЦЕННЫЙ TELEGRAM MINI APP — SHMIT HUB

Я прикрепляю несколько изображений-референсов. Сначала внимательно проанализируй все изображения, их композицию, визуальный язык, цвета, градиенты, карточки, скругления, типографику, свечение, spacing и расположение элементов.

ГЛАВНОЕ ПРАВИЛО

ПЕРВЫЙ РЕФЕРЕНС — ГЛАВНЫЙ И СТРОГИЙ ВИЗУАЛЬНЫЙ РЕФЕРЕНС.

Не придумывай новый дизайн. Не делай стандартный шаблонный dashboard. Не упрощай интерфейс.

Нужно создать полноценный Telegram Mini App, который визуально ощущается как реализация первого референса в виде настоящего мобильного приложения.

Все элементы, которые я отдельно не попросил изменить, должны максимально соответствовать первому референсу.

Второй референс используется только для копирования иконок и названий нижней навигации. Не копируй с него общий дизайн.

6. ВАЖНОЕ ИЗМЕНЕНИЕ ТРЕТЬЕГО ЭКРАНА

На третьей карточке/списке услуг из первого референса сейчас присутствуют светящиеся линии около каждого пункта.

ПОЛНОСТЬЮ УДАЛИ ЭТИ СВЕТЯЩИЕСЯ ЛИНИИ.

Не оставляй даже слабое свечение.

Вместо этих линий используй мягкий градиент, аналогичный общему градиенту и цветовой атмосфере первого референса.

То есть:

❌ старые светящиеся разделители удалить;

✅ вместо них использовать мягкий градиент;

✅ градиент должен выглядеть частью существующего дизайна;

✅ не создавать новый стиль;

✅ не добавлять дополнительный neon-эффект.

Сам список, текст, порядок пунктов, карточки, размеры, иконки и структура должны остаться прежними, если я отдельно не указал обратное.

современной;

аккуратной;

премиальной;

Она не должна выглядеть как обычный прямоугольный navbar.

Она должна визуально восприниматься как floating glass dock.

Активный пункт выделяется фирменным оранжевым цветом и мягким orange glow.

Неактивные пункты — спокойный светло-серый/приглушённый цвет.

16. ФИНАЛЬНОЕ ТРЕБОВАНИЕ

Перед тем как считать работу завершённой, проверь:

Первый референс полностью сохранён как основа дизайна.

Второй референс используется только для иконок и названий нижней навигации.

Нижняя панель стала более округлой, красивой и адаптированной под первый дизайн.

На Welcome нижней панели НЕТ.

На SHMIT HUB, Услугах и Профиле нижняя панель ЕСТЬ.

На третьем экране удалены светящиеся линии возле пунктов.

Вместо них используется градиент в стиле первого референса.

PNG-логотипы проектов вставлены без каких-либо изменений.

Никакие другие элементы первого референса самовольно не изменены.

Не добавлены лишние разделы и элементы.

Интерфейс выглядит как единый цельный premium Telegram Mini App.

В результате не должно быть ощущения, что элементы собраны из разных шаблонов.
